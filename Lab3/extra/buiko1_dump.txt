[P40] Требования к разрабатываемому приложению
[P42] Приложение «File Searcher» (далее FS) (Недвусмысленность, аббревиатура и для File System) предназначено для автоматического поиска файлов по заданному шаблону.
[P44] Приложение должно быть написано на Delphi 7 и работать под Win XP и Win 7. (Актуальность, Выполнимость. Требование использовать устаревшую Delphi 7 и заброшенные Windows XP/7 делает проект устаревшим и нерабочим на современных Windows 10/11.)
[P46] Для поиска указывается начальный каталог или набор каталогов. FS автоматически сканирует каталоги на неограниченную глубину вложенности (Выполнимость, Надежность) и отображает все найденные файлы в правой панели (см. скриншот 1). (Атомарность, разделить пункт на отдельные)
[P48] Для поиска доступно три типа файлов (Непротиворечивость, перечисленно 11 расширений) (выбор производит вручную или с помощью комбо-бокса «Что искать»):
[P49] Аудиофайлы (mp3, ogg, wav, mid).
[P50] Видеофайлы (avi, mpg, mpeg).
[P51] Офисные файлы (doc, docx, xls, xlsx).
[P53] По всем найденным файлам отображается:
[P54] Имя.
[P55] Полный путь.
[P56] Размер.
[P57] Дата-время создания файла.
[P58] Скриншот с первым кадром. (Непротиворечивость, нельзя получить скриншот для всех типов файлов)
[P60] Производительность.
[P61] FS должно искать не менее 500 файлов в секунду при условии, что скорость чтения/записи на диск превышает 50 Мб в секунду. (Тестируемость, Корректность, Недвусмысленность. Скорость поиска не зависит от скорости чтения/записи самих данных файла)
[P62] В случае, если общее время операции превышает 1 час, приложение не должно начинать работу. (Тестируемость, Реализуемость.)
[P64] Поддержка языков.
[P65] Приложение должно поддерживать русский и английский языки по умолчанию.
[P66] Должна быть возможность добавлять новые языки.
[P68] Логирование.
[P69] FRS должно вести лог своей работы. (Недвусмысленность, опечатка)
[P70] Если размер лога превышает 1 Мб, ведение лога прекращается.
[P71] Текущий анализируемый каталог должен отображаться в панели «Сейчас проверяется» внизу экрана. (Непротиворечивость (согласованность с UI))
[P73] Поддержка файловых систем:
[P74] Должны поддерживаться все файловые системы Windows и UNIX.
[P75] В случае обнаружения неподдерживаемой FS, FS должно аварийно завершать работу. (Корректность, Надежность. Приложение должно корректо обрабатывать исключения)
[P77] Должна быть поддержка сети. (Недвусмысленность, Избыточность, Формулировка Должна быть, сеть не необходима)
