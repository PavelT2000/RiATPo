# Требования к разрабатываемому приложению

## 1. Суть проекта

Приложение «File Searcher» (далее — приложение) — настольная утилита для ОС Windows, предназначенная для поиска аудио-, видео- и офисных файлов в локальных и сетевых каталогах по категории или маске и вывода сведений о найденных файлах в таблицу.

## 2. Основные цели проекта

a) Сократить время, которое пользователь тратит на поиск медиафайлов и документов на дисках компьютера и в сетевых папках.
b) Обеспечить работу на рабочих станциях под Windows XP и Windows 7 без установки дополнительного программного обеспечения.

## 3. Критерии достижения целей проекта

a) Поиск по каталогу, содержащему 50 000 файлов, на эталонном стенде (п. 8.1) занимает не более 100 секунд.
b) Приложение запускается на чистых ОС Windows XP SP3 и Windows 7 SP1 без установки библиотек и без прав администратора.

## 4. Риски

a) Искажение кириллических имён файлов: строки Delphi 7 по умолчанию однобайтовые (ANSI).
b) Зависание поиска при недоступной сетевой папке или обрыве сети.
c) Зацикливание обхода на точках соединения (Junction) и символических ссылках NTFS.

## 5. Системные характеристики

a) Операционная система: Windows XP SP3, Windows 7 SP1 (32- и 64-разрядные).
b) Аппаратные требования:
   - Процессор: x86 с частотой от 1 ГГц.
   - Оперативная память: не менее 256 МБ свободной ОЗУ.
   - Дисковое пространство: 10 МБ.
c) Поддерживаемые файловые системы: NTFS, FAT32, exFAT (в Windows XP — с обновлением KB955704) и сетевые папки по протоколу SMB.
d) Приложение поставляется одним исполняемым файлом FileSearcher.exe и не требует установки.

## 6. Пользовательские требования

a) Пользователь указывает каталог или список каталогов для поиска вводом пути в поле «Где искать» либо выбором папки кнопкой «…».
b) Пользователь выбирает категорию файлов в комбо-боксе «Что искать» или вводит собственную маску.
c) Пользователь запускает поиск кнопкой «Искать» и досрочно прекращает его кнопкой «Остановить».
d) Пользователь просматривает найденные файлы в таблице, сортирует её по столбцам и видит первый кадр выбранного видеофайла в панели «Предпросмотр».
e) Пользователь переключает язык интерфейса (русский или английский) через меню «Language» без перезапуска приложения.

## 7. Бизнес-правила

a) Категории включают следующие расширения:
   - Аудиофайлы: .mp3, .ogg, .wav, .mid.
   - Видеофайлы: .avi, .mpg, .mpeg.
   - Офисные файлы: .doc, .docx, .xls, .xlsx.
b) Расширения и маски сравниваются без учёта регистра букв.
c) Глубина обхода — не более 64 уровней вложенности от начального каталога; точки соединения и символические ссылки не раскрываются.
d) Каталоги и файлы без прав на чтение, тома с неподдерживаемой файловой системой и пути длиннее 260 символов пропускаются с записью WARNING в журнал, поиск продолжается.
e) Сетевая папка, не ответившая в течение 10 секунд, пропускается с записью в журнал.
f) Лимит времени поиска по умолчанию — 60 минут. По его истечении поиск приостанавливается, и приложение предлагает пользователю продолжить или завершить поиск.

## 8. Атрибуты качества

### 8.1. Производительность

a) На эталонном стенде (Intel Core i3, 4 ГБ ОЗУ, HDD SATA 7200 об/мин, NTFS) приложение проверяет не менее 500 файлов в секунду на локальном диске.
b) Поиск выполняется в отдельном потоке; время отклика окна на действия пользователя во время поиска не превышает 0,5 секунды.

### 8.2. Надёжность

a) При ошибке доступа, повреждённом файле или обрыве сети приложение пропускает объект, записывает событие в журнал и продолжает поиск без аварийного завершения.
b) После остановки поиска (вручную или по лимиту времени) найденные файлы остаются в таблице.

### 8.3. Удобство использования

a) Все элементы управления доступны с клавиатуры, поиск запускается клавишей Enter из поля «Где искать».
b) Текущий проверяемый каталог отображается в строке состояния внизу окна в режиме реального времени.

### 8.4. Локализация

a) Все надписи и сообщения интерфейса переведены на русский и английский языки.
b) При первом запуске язык выбирается по языку ОС; если язык ОС не русский, используется английский.
c) Новый язык добавляется файлом перевода в папке Lang без перекомпиляции (п. 10.5).

## 9. Ограничения

a) Приложение разрабатывается на Delphi 7; для работы с именами файлов используются Unicode-функции Win32 API (FindFirstFileW, FindNextFileW).
b) Поиск выполняется только по именам файлов, поиск по содержимому не поддерживается.
c) Приложение не открывает и не воспроизводит найденные файлы.
d) Разделы UNIX (ext2/3/4) доступны только как сетевые папки; FTP, WebDAV и облачные хранилища не поддерживаются.

## 10. Детальные спецификации

### 10.1. Выбор каталогов

a) Поле «Где искать» принимает до 1024 символов; пути разделяются символом «;», пробелы по краям путей удаляются.
b) Допускаются UNC-пути сетевых папок (\\server\share) и локальные пути (C:\Music).
c) Кнопка «…» открывает стандартный диалог выбора папки Windows и добавляет выбранный путь в конец строки поля.
d) Перед поиском приложение проверяет существование каждого пути: несуществующие пути пропускаются с сообщением, а если корректных путей нет, поиск не запускается.

### 10.2. Параметры поиска

a) Комбо-бокс «Что искать» содержит пункты:
   - «Аудиофайлы»;
   - «Видеофайлы»;
   - «Офисные файлы».
b) Поле комбо-бокса редактируемое: пользователь вводит маску со знаками * и ?, маски разделяются символом «;» (например, *.pdf;report*.*).
c) Лимит времени поиска задаётся в минутах в файле настроек FileSearcher.ini; значение 0 отключает лимит.

### 10.3. Процесс поиска

a) Нажатие кнопки «Искать» запускает поиск; на время поиска надпись кнопки меняется на «Остановить», поля ввода блокируются.
b) Нажатие кнопки «Остановить» прекращает поиск не позднее чем через 1 секунду.
c) По истечении лимита времени выводится диалог «Поиск длится больше N мин. Продолжить?» с кнопками «Продолжить» и «Завершить».
d) Счётчик «Найдено файлов» обновляется по мере обнаружения файлов.

### 10.4. Отображение результатов

a) Таблица результатов содержит столбцы:
   - № (порядковый номер).
   - Имя (имя файла с расширением).
   - Путь (полный путь к каталогу).
   - Размер (в Б, КБ, МБ или ГБ с одним знаком после запятой).
   - Создан (дата-время создания в формате ДД.ММ.ГГГГ ЧЧ:ММ).
   - Изменён (дата-время последнего изменения в том же формате).
b) Щелчок по заголовку столбца сортирует таблицу по возрастанию, повторный щелчок — по убыванию.
c) При выборе строки с видеофайлом панель «Предпросмотр» справа от таблицы показывает его первый кадр; для аудио- и офисных файлов, а также при ошибке декодирования показывается значок типа файла.
d) Строка состояния внизу окна выводит текст «Сейчас проверяется: <путь>».

### 10.5. Журналирование и файлы перевода

a) Приложение ведёт журнал FileSearcher.log в каталоге программы; каждая запись содержит дату-время, уровень (INFO, WARNING, ERROR) и текст события.
b) При достижении размера 1 МБ (1 048 576 байт) запись в журнал прекращается, последней добавляется запись «Достигнут предельный размер журнала», в строке состояния выводится предупреждение.
c) При следующем запуске прежний журнал переименовывается в FileSearcher.old.log, и запись начинается в новый файл.
d) Файл перевода — текстовый файл UTF-8 со строками вида ключ=значение, имя файла — код языка (ru.lng, en.lng).
